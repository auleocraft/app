# AuLeo Craft

**Hide your voice. Keep it natural.**

Browser-based voice disguiser for voiceovers — record or upload audio, disguise your voice with natural-sounding presets, and download the result. Built for Facebook, YouTube, and TikTok creators who don't want their real voice recognized.

## Features

- Record or upload audio (MP3, WAV, M4A, OGG, WEBM)
- Disguise presets: Soft / Medium / Strong, Deeper / Higher / Older voice
- Custom sliders: Pitch, Timbre, Speed, Reverb, Bass, Treble, Echo, Distortion
- A/B compare: original vs disguised
- Batch processing for multiple files
- WAV download with real progress display

## Privacy

100% client-side — audio never leaves your device. No server, no uploads. Works offline after the page loads.

## Use

Open `index.html` in any modern browser, or visit the GitHub Pages site.
